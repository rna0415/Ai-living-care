## 안전 — 담당자 통지 (⚠ 미해소 · D-18)

**이 표가 소유 경계를 넘는 유일한 통로다.** 결함은 담당자 코드에 있고 생태계 담당은 고치지
않는다(D-17). 대신 **`docs/safety/` 에 파일 하나**를 만들고 **귀속 컴포넌트 `CLAUDE.md` 의
`상태` 줄에 같은 ID 를 박는다.** `anchor.py` A5 가 두 자리의 짝을 **양방향으로** 강제한다 —
파일을 지워도, `상태` 줄에서 지워도 커밋이 막힌다. 지우려면 두 곳을 같이 지워야 하고,
그건 「해소했다」는 선언이다.

**목록은 여기 두지 않는다.** 결함이 늘 때마다 자동 로딩 예산이 늘면 **결함을 기록하는 일이
예산에 막힌다** (`status-defects.md` 를 분리한 것과 같은 이유). 대신 두 경로로 간다:

- `make status` **맨 위**에 미해소 목록이 뜬다 — 세션 시작에 한 번 (하네스 §0)
- 귀속 컴포넌트 `CLAUDE.md` 의 `상태` 줄 — 그 컴포넌트를 건드리는 사람이 먼저 읽는 문서

> 미해소 결함들은 하네스가 「안전 경로」로 지정한 축과 정확히 겹친다 — **로봇 정지·취소** ·
> **사람 검출→판정** · **프레임 신선도**. 그래서 실행 차단(`F-4`~`F-10`)과 분리해 둔다.

**담당자가 해소하는 절차** — 셋을 한 PR 에서 함께 한다:

1. 코드를 고친다. 이 트리는 담당자 소유이므로 별도 승인이 없다.
2. **실패 경로를 한 번 실행하고 출력을 PR 에 붙인다.** 안전 결함은 「고쳤다」로 닫지 않는다.
3. `docs/safety/` 의 파일과 컴포넌트 `상태` 줄의 ID 를 **함께 지우고** 아래 표에 한 줄 남긴다.
